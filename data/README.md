# data

원고·평가 자료를 두는 곳이다. 이 폴더의 내용은 Git에 넣지 않는다(`.gitignore`). 기밀 원고를 외부로 보내지 않는다.

## private/

심사 의뢰 원고처럼 비공개인 원고와 그에 대한 리뷰를 둔다.

- 파일 이름에 논문 제목을 쓰지 않는다. 예: `manuscript-001.pdf`, `manuscript-001-review.docx`
- 코딩 에이전트는 이 폴더를 읽지 못하게 막혀 있다(`.claude/settings.json`, `.agents/hooks/guard.conf`). 에이전트가 읽으면 내용이 모델 제공자 서버로 전송되기 때문이다.
- 이 폴더의 파일로 프로그램을 돌릴 때는 사용자가 직접 실행하고, 결과의 원문 부분은 에이전트에게 붙여 넣지 않는다.
