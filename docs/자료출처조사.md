# 자료 출처 조사 (T002.1)

- 목적: Chemical Engineering 영어 논문 가운데 사람 작성 기준 자료(2022년 이전 공개)와 AI 변형본의 씨앗으로 쓸 수 있는 공개 출처를 고른다.
- 조사일: 2026-10-03. 수치는 아래 API를 그날 직접 조회한 값이다. 이용 조건 해석은 개발 판단이며 법률 검토가 아니다.
- 기간 기준: 2017~2021년 공개분. ChatGPT 공개(2022-11-30) 이전이지만, 그 전에도 AI 문장 바꾸기 도구가 있었으므로 "AI 관여 없음"은 확정이 아니라 높은 가능성이다. 이 한계는 정답 근거 D 수준으로 기록한다(라벨 지침 2절).

## 1. 비교표

- 주제 거르기 시험: RSC Advances·ACS Omega·Membranes의 CC BY 원문에서 제목·초록에 화학공학 주제어 5개(chemical engineering, process design, reactor, distillation, adsorption) 중 하나가 있는 논문은 790편이었다. 주제어를 늘리면 더 많아질 수 있다.
- XML 시험(PMC9082319, RSC Advances 2019, CC BY): 절 20개, 문단 40개, 수식 2개, 참고문헌 22개, 아래첨자 124곳이 태그로 구분되어 있다. 이용 조건은 XML 본문에 없고 검색 메타데이터(`license`)에 있으므로 목록에 따로 기록해야 한다.

## 2. 이용 조건 판단

- **CC BY:** 분석, 변형본 생성, 외부 API 전송이 모두 허용된다고 본다. 출처 표기만 지키면 된다. 변형본 씨앗은 CC BY만 쓴다.
- **CC BY-NC:** 비상업 연구 목적이면 분석과 변형이 가능하다고 본다. 다만 외부 상용 API에 보내는 것이 비상업 조건과 충돌하지 않는지는 판단이 갈릴 수 있다. 사람 작성 집단의 분석용으로만 쓰고, 변형본 씨앗에서는 뺀다.
- **ND(변형 금지)·출판사 자체 조건:** 변형본 씨앗에서 제외한다.
- 근거: 각 라이선스 원문(https://creativecommons.org/licenses/by/4.0/ 등). 직접 대조는 하지 않았고 일반적인 해석을 따랐다(확인 수준: 간접).

## 3. 권고

1. **주 출처는 Europe PMC 경유 CC BY 원문으로 한다.** RSC Advances와 Membranes 등에서 받는다. XML이라 수식·표·참고문헌을 깔끔하게 분리할 수 있고, API로 이용 조건과 함께 자동 수집할 수 있다. 화학공학 주제로 거른 뒤에도 사람 작성 시험용 300편 이상은 확보할 수 있을 것으로 본다. 정확한 수는 T002.4에서 센다.
2. **MDPI Processes는 내려받기 방법을 확인한 뒤 추가한다.** 화학공학 핵심 학술지라 분야 대표성을 높여 준다.
3. **ChemRxiv는 PDF 입력 처리 시험(T002.2)에 소수를 쓴다.** 실제 투고 원고와 형태가 비슷하다. 대량 수집은 API 접근을 확인한 뒤 정한다.
4. **ACS Omega와 CC BY-NC 논문은 변형본 씨앗에서 제외한다.**

## 4. 남은 확인

- RSC Advances와 Membranes에서 화학공학 범위를 정하는 주제어나 분류 기준 (T002.4, 목표 정의서 6절의 세부 경계와 함께)
- MDPI 사이트의 대량 내려받기 허용 여부와 방법
- ChemRxiv API 접근 방법(이번 조회는 403)
- 2017~2021 자료 안에서 2020~2021 공개분을 따로 표시해, AI 문장 바꾸기 도구가 영향을 줬는지 시기별로 비교할 수 있게 할지

## 5. 조회 방법 (재현용)

- Europe PMC: `https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=JOURNAL:"RSC Advances" AND PUB_YEAR:[2017 TO 2021] AND IN_PMC:y AND LICENSE:"cc by"&format=json`. 원문은 `.../rest/{PMCID}/fullTextXML`
- Crossref: `https://api.crossref.org/works?filter=issn:2227-9717,from-pub-date:2017-01-01,until-pub-date:2021-12-31,type:journal-article&rows=0`
- ChemRxiv 전체 수: Crossref `prefix:10.26434,type:posted-content`
