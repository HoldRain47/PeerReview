# AI 변형본 생성 규칙 (T002.5)

- 목적: 사람이 쓴 씨앗 논문의 일부를 AI로 바꿔 "AI가 관여한 논문"을 만든다. 무엇을 어디서 어떻게 바꿨는지 기록이 남으므로, 이 변형본은 정답 근거 A(통제된 작성 과정 기록)가 된다.
- 근거: tasks/plan.md 2절(짝 설계)·T002.5, docs/라벨지침-v26100302.md 3·5절, AGENTS.md 4절(공개 논문 외부 API 예외)
- 상태: 시범(씨앗 5편 × 행위 5개 = 25개). 규모는 점검 2에서 정한다.
- 코드: `src/peerreview/variants.py`(지시문·조립·점검), `scripts/make_variants.py`(실행)

## 1. 사용자 결정 (2026-10-04)

| 항목 | 결정 |
|---|---|
| 모델 계열 | Claude, OpenAI. Gemini는 제외 |
| Claude 실행 | API 키 없이 Claude Code 하위 에이전트(Sonnet)가 만든다. 프로젝트 지침의 "반복 작업은 가벼운 모델에 위임"을 따름 |
| OpenAI 실행 | 사용자의 API(충전 5달러). 시범 지출 상한 1달러 |
| 번역 대조군 | 넣는다. 사람이 쓴 모국어 원문이 없어 대용 방식(영어→한국어→영어)으로 만든다 |

## 2. 무엇을 바꾸나

- 대상: 씨앗 논문 서론(Introduction) 절의 앞 문단 3개. 문단마다 60단어 이상이고 수식이 없어야 한다. 조건에 맞지 않는 씨앗은 건너뛴다.
- 나머지 절은 씨앗 원문 그대로다. 그래서 변형본 한 편은 "일부 구간만 AI가 관여한 논문"이다(라벨 지침 L15와 같은 형태).
- 바꾼 문단의 위치(`body[1]/sec[1]/p[1]` 같은 JATS 경로)를 라벨의 `spans`에 남긴다. 구간 정답이다.
- 바꾼 문단은 글자만 남는다. 원래 문단에 있던 인용 표시 태그와 각주 태그는 지워진다(글자 `[1]`는 모델 출력에 남아 있을 수 있다).

## 3. 행위별 지시

지시문은 실제 저자가 채팅 도구에 넣을 법한 짧은 영어 요청이다. 문구는 `variants.build_steps`에 있다.

| 행위 | 모델에 주는 것 | 지시 요지 | 라벨 지침 대응 |
|---|---|---|---|
| 생성 | 논문 제목, 초록 | 서론 앞 문단 3개를 원래 길이쯤으로 써라 | L06(원문 없이 문장 산출) |
| 재작성 | 원래 문단 3개 | 명확성·흐름·학술 문체를 좋게 다시 써라. 뜻과 인용 표시는 유지 | L03 |
| 교정 | 원래 문단 3개 | 철자·문법·구두점 오류만 고쳐라. 표현을 바꾸지 마라 | L01 |
| 번역(대용) | 1단계: 원래 문단 3개 / 2단계: 1단계 한국어 출력만 | 한국어로 옮겨라 → 화학공학 논문용 영어로 옮겨라 | L04(대용) |
| 혼합 | 문단마다 앞쪽 절반 문장 | 각 문단의 이어지는 문장만 써라. 앞 절반 원문 + AI 문장으로 문단을 만든다 | L08 |

AI 초안을 사람이 수정한 경우(L07)는 사람 편집이 필요해 시범에서 뺐다. 필요하면 사용자가 AI 초안 몇 개를 직접 고치는 방식으로 나중에 더한다.

## 4. 배정과 기록

- 씨앗 5편 × 행위 5개에 모델 계열을 번갈아 배정한다(시드 20261004). 시범 배정은 Claude 12개, OpenAI 13개다.
- 생성 기록(`data/public/variants/`, Git 제외):
  - `tasks.jsonl`: 지시문 원문, 바꿀 위치, 혼합의 남긴 앞부분
  - `outputs-*.jsonl`: 모델 이름(응답에 찍힌 실제 이름), 단계별 원출력, 생성 시각, 토큰 수와 비용(OpenAI)
  - `xml/`: 변형본 XML
  - `report.json`: 점검 결과
- 자료 목록(`data/manifest.jsonl`)에 `role=variant`, 씨앗과 같은 `bundle_id`, 근거 A로 넣는다. 라벨(`data/labels.jsonl`)은 씨앗이 근거 D·행위 없음, 변형본이 근거 A·해당 행위다.

## 5. 의도대로 바뀌었는지 점검

모델이 지시를 그대로 따르지 않을 수 있다. 예를 들어 "교정만"이라고 해도 표현을 바꾸기도 한다. 그래서 라벨은 의도가 아니라 결과로 붙인다(라벨 지침 3절 "기능 이름이 아니라 입출력으로 정한다").

| 의도 | 결과 조건 | 라벨 |
|---|---|---|
| 교정 | 낱말 순서 유사도 0.9 미만이거나 문장 수가 바뀜 | 재작성(라벨 지침 5절) |
| 교정 | 원문과 같음 | 교정(기록에 "바뀐 곳 없음") |
| 재작성 | 유사도 0.97 이상(거의 안 바뀜) | 교정 |
| 생성·번역·혼합 | — | 의도대로 |

자동 점검 뒤 사용자가 행위마다 1건씩, 모두 5건을 원문과 나란히 보고 라벨이 맞는지 확인한다. 공개 논문이라 대화에 보여 줘도 된다.

## 6. 안전 장치

- 외부 모델로 보내는 것은 자료 목록에서 `role=seed`, 이용 조건 `cc by`, 출처 `europepmc`인 공개 논문뿐이다(`prepare`에서 거름). 비공개 원고 폴더는 코드가 다루지 않고 에이전트 접근도 막혀 있다.
- OpenAI 키는 환경 변수 `OPENAI_API_KEY`나 저장소 루트 `.env`에서만 읽는다. `.env`는 Git 제외이고, 에이전트의 읽기·셸 출력이 막혀 있다. 오류가 나도 HTTP 상태 코드만 낸다.
- 비용: 호출 전에 다음 호출 비용을 넉넉히 어림해, 누적 비용이 상한(1달러)을 넘을 것 같으면 멈춘다. 실제 비용은 응답의 토큰 수로 기록한다.

## 8. 한계

- **번역은 대용이다.** AI가 만든 한국어를 다시 AI가 영어로 옮겼으므로, 사람이 모국어로 쓴 초안의 AI 번역과 문체가 다를 수 있다.
- **Claude는 하위 에이전트로 만든다.** API처럼 온도 같은 설정을 고정할 수 없고, 같은 지시를 다시 줘도 같은 출력이 나온다는 보장이 없다. 원출력을 모두 저장해 재현을 대신한다.
- **서론 앞 3문단만 바꾼다.** 방법·결과·고찰 절의 AI 관여는 이번 시범에 없다.
- **시범 혼합 작업은 약어 뒤에서 잘린 문단이 있다.** 문장 나누기가 "et al.", "e.g." 뒤를 문장 끝으로 봐서, 남긴 앞부분이 문장 중간에서 끝난 경우가 있다. 모델이 그 뒤를 이어 써 문단은 자연스럽지만 "앞 절반 문장"이라는 설계와 다르다. 시범 뒤 약어를 알아보게 고쳤다.
- **OpenAI 모델의 정확한 버전을 모른다.** `chat-latest`는 ChatGPT가 쓰는 최신 모델을 가리키는 이름이라, 시점이 바뀌면 다른 모델이 응답한다. 생성 시각을 기록해 시점으로 구분한다.
- **모델 버전은 시범 시점의 것이다.** 새 모델이 나오면 영향을 다시 평가해야 한다(v2.0 8절 6단계).
