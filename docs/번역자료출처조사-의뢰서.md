# 조사 의뢰서: 한국어 화학공학 논문과 그 사람 번역본 출처 (T002.9)

> 이 문서 전체를 검색 에이전트에게 그대로 전달한다. 결과는 맨 아래 "반환 형식"대로 받는다.
> 작성일 2026-10-04. 비공개 원고나 개인 정보는 들어 있지 않다.

## 1. 배경 (에이전트용 설명)

우리는 영어로 된 화학공학(Chemical Engineering) 연구 논문 원고에서, 작성 과정에 생성형 AI가 관여했는지를 단계별로 판단하는 도구를 만들고 있다. 대상 원고는 주로 한국인 저자가 쓴 것이다. 많은 원고가 다음 경로 중 하나를 거친다.

1. 한국어로 쓴 뒤 사람 번역가(전문 기관)가 영어로 옮김
2. 기계 번역(Papago, Google 번역, DeepL)으로 옮김
3. 생성형 AI(ChatGPT 등)로 옮김
4. 처음부터 영어로 씀

도구가 "사람 번역 원고를 AI로 잘못 판정하지 않는지" 시험하려면, **사람이 쓴 한국어 화학공학 논문**과 **그 논문을 사람이 영어로 번역한 글**이 짝으로 필요하다. 생성형 AI가 퍼지기 전의 자료여야 사람 작성·사람 번역이라고 볼 수 있다.

## 2. 찾을 것

### 2.1 가장 좋은 자료: 짝 자료
같은 화학공학 논문의 **한국어 원문 + 사람이 번역한 영어판**.
- 예: 한국어판과 영어판을 함께 내는 국내 학술지, "영문 번역본"을 따로 싣는 학술지, 한영 두 언어로 공개하는 기관 보고서
- 번역을 사람이 했다는 근거(학술지의 번역 정책, "translated by" 표기, 번역 기관 명시 등)가 있으면 함께 적는다.

### 2.2 그다음 자료: 한국어 원문만
사람이 쓴 한국어 화학공학 논문(본문 전체가 한국어). 영어판이 없어도 된다(기계 번역·AI 번역본은 우리가 만든다). 단, 아래 이용 조건을 만족해야 한다.

### 2.3 참고 자료: 다른 형태의 사람 번역 짝
화학공학 분야의 다른 문서 중 사람 번역 짝이 확실한 것. 예: 한국 특허 출원과 같은 발명의 영어 특허(PCT·미국 출원). 문체가 논문과 다르다는 한계를 적는다.

## 3. 조건

| 항목 | 조건 |
|---|---|
| 분야 | 화학공학 넓은 범위: 반응공학, 분리(막·흡착·증류), 공정 설계, 전달현상, 촉매, 재료 합성, 전기화학, 생물공정 |
| 시기 | **2017~2021년 공개분**(ChatGPT 공개 2022-11-30 이전). 2016년 이전도 있으면 따로 적는다 |
| 이용 조건 | 분석 목적의 내려받기와 가공이 허용될 것. **외부 AI API(OpenAI·Anthropic)로 본문을 보내 번역본을 만들어도 되는지**를 반드시 확인한다. CC BY가 가장 좋다. CC BY-NC는 따로 표시. 이용 조건이 불분명하면 "확인 못함" |
| 형식 | XML(JATS 등) > 글자가 뽑히는 PDF > 스캔 PDF. 한국어 본문 전체가 있어야 한다(초록만 있는 것은 따로 표시) |
| 접근 | 대량 내려받기 방법(API·OAI-PMH·일괄 파일)이 있는지, 회원 가입·유료 여부 |

## 4. 살펴볼 곳 (예시, 이것만으로 한정하지 않음)

- KCI(한국학술지인용색인) 공개 논문과 OpenAPI
- KoreaScience(한국과학기술정보연구원), ScienceON API
- 국내 화학공학 관련 학술지: 「화학공학」(Korean Chemical Engineering Research, 한국화학공학회), 「공업화학」(Applied Chemistry for Engineering), 「청정기술」, 「멤브레인」, 「한국수소 및 신에너지학회 논문집」, 「Korean Journal of Chemical Engineering」(영문지) 등. 각 학술지의 언어 정책(한국어 본문인지, 영어판을 따로 내는지)과 오픈 액세스 라이선스를 확인
- 한영 병행 출판 사례를 다룬 기사·학회 공지
- KIPRIS(한국 특허)와 대응 영어 특허(2.3용)

## 5. 지켜 줄 것

- 확인한 사실만 적는다. 추측은 "추정"으로, 확인하지 못한 것은 "확인 못함"으로 쓴다.
- 모든 수치와 이용 조건에는 **출처 주소와 확인일**을 붙인다.
- 확인 수준을 적는다. **직접**은 공식 페이지나 라이선스 원문을 읽은 것이고, **간접**은 검색 요약이나 제3자 글이다.
- 논문 본문을 대량으로 내려받지 않는다. 조사는 메타데이터, 이용 조건, 표본 몇 편 확인까지만 한다.
- 결과에 개인 연락처나 저자 개인 정보를 넣지 않는다.
