## 1. 목표

제출된 논문의 작성 과정에 생성형 AI가 관여했는지를 근거에 따라 판단하고, 판단·근거·한계를 리뷰로 전달한다. 개발의 성패는 지원 범위에서 목표 행위를 얼마나 구별하는지와 잘못된 판단을 얼마나 통제하는지로 평가한다(v2.0 1절). 리뷰 문장의 자연스러움은 완료 조건이 아니다.

## 2. 최초 지원 범위 (결정)

| 문서 단위 | 논문 전체를 판정 단위로 한다. 문단·문장 표시는 근거 위치 안내용이다 | v2.0 2절 | 구간 정답이 있는 자료를 확보해 위치 평가를 따로 할 때 |

지원 범위 밖 입력(영어가 아닌 원고, 다른 분야, 학위논문·초록만·서평·사설 등)은 처리 상태를 `out_of_scope`로 기록하고 판정하지 않는다. 범위 밖이라는 사실을 AI 미사용으로 해석하지 않는다.

리뷰 출력 언어는 아직 정하지 않았다(6절). 출력 언어와 탐지 지원 언어는 별개다(v2.0 2절).

## 3. 관여 행위와 목표 행위

관여 행위 정의와 경계 사례는 라벨 지침에 둔다. 코드 어휘는 `src/peerreview/model.py`의 `InvolvementAct`와 `TARGET_ACTS`다.

| 관여 행위 | 코드 값 | 1차 목표 행위 |
|---|---|---|
| 본문 생성 | `generation` | 예 |
| 재작성 | `rewriting` | 예 |
| 혼합 작성 | `mixed` | 예(생성 포함). 결과는 따로 보고 |
| AI 초안을 사람이 수정 | `human_edited_ai` | 예(생성 포함). 결과는 따로 보고 |
| 교정 | `proofreading` | 아니오. 목표 행위로 표시하면 오탐 |
| 번역 | `translation` | 아니오. 목표 행위로 표시하면 오탐 |
| 검색·아이디어 정리 | `search_ideation` | 아니오 |
| 연구 대상으로서의 AI 출력 인용 | `quoted_ai_output` | 아니오 |
| 미상 | `unknown` | 판단하지 않음. 확정 정답에서 제외 |

`search_ideation`은 이번에 추가했다. v2.0 1절과 검토서 5절이 검색·아이디어 정리를 본문 생성과 구분하라고 했으나 기존 어휘에 해당 값이 없었다.

## 4. 결과 상태

증거 수준과 처리 상태는 서로 독립된 두 축으로 기록한다(v2.0 3절). AI 미사용을 확인하는 값은 두지 않는다.

증거 수준(`EvidenceLevel`):

| 값 | 의미 | 부여 조건 |
|---|---|---|
| `record_confirmed` | 작성 자료로 확인한 관여 | 원출력·변경 이력의 출처와 진위를 확인하고 문서·시점·구간에 연결한 경우만. 확인한 행위와 구간으로 범위를 한정한다 |
| `text_estimate` | 텍스트 기반 추정 | 방법이 지원 범위의 독립 시험에서 수용 기준을 충족했고, 이 논문의 결과가 사전 고정된 판정 기준을 넘은 경우만 |
| `style_signal` | 문체 신호 관찰 | 성능을 검증하지 않은 목록·정규식 일치. 문자열 존재에 관한 결과일 뿐이다 |
| `unverified_record` | 진위·연결 미확인 자료 | 자료는 있으나 진위나 원고와의 연결을 확인하지 못한 경우 |
| `withheld` | 판단 유보 | 유효한 신호가 없거나 근거가 부족한 경우. 미사용 확인이 아니다 |

처리 상태(`ProcessingStatus`): `completed`(분석 완료), `partial`(일부 처리), `extraction_failed`(추출 실패), `too_short`(분량 부족), `out_of_scope`(지원 범위 밖). 신호가 없어도 결과 파일을 만들고, 검사한 범위와 제외한 범위를 남긴다.

`text_estimate`는 4단계(대안 비교와 독립 시험)를 통과한 방법이 생기기 전까지 부여할 수 없다. 그 전의 텍스트 분석 결과는 모두 `style_signal` 또는 `withheld`다.

## 5. 수용 기준의 결정 책임과 시점

| 항목 | 내용 |
|---|---|
| 정할 기준 | 허용 오탐률, 그 조건에서 필요한 재현율, 유보율, 처리량 (v2.0 6절) |
| 기준에 함께 적을 것 | 목표 행위, 지원 집단, 평가 단위(논문), 신뢰구간, 기준을 고른 업무상 이유, 미달 시 조치 |
| 결정 책임자 | 사용자(프로젝트 책임자) |
| 결정 시점 | T002에서 평가 자료의 규모와 구성을 확인한 뒤, 4단계 최종 시험을 시작하기 전. 최종 시험 결과를 본 뒤에는 기준을 바꾸지 않는다 |
| 지금 정하지 않는 이유 | 사용 규모와 오판 후 조치가 정해지지 않았다. 음성 표본이 100편이면 오탐 0건이어도 단측 95% 상한이 약 2.95%라서, 기준 수치는 확보 가능한 표본 수와 함께 정해야 한다(v2.0 6절 계산 예시) |

미달하면 해당 범위의 운영을 보류하거나 지원 범위를 명시적으로 좁힌다. 기준을 낮추거나 목적을 문체 교정으로 바꿔 완료 처리하지 않는다.

## 6. 아직 정하지 않은 것

- 리뷰 출력 언어: 검토서 3절은 한 언어로 먼저 안정화하고 번역은 뒤에 붙이라고 권한다. 5단계 전까지 정한다.
- 분량 부족(`too_short`)의 기준 길이: 기준선 측정(T003)에서 길이별 결과를 본 뒤 정한다. ADAFAI의 150단어는 이 프로젝트에서 검증한 값이 아니다(v2.0 7절).
- Chemical Engineering의 세부 경계(예: 촉매·전기화학·재료·생물공정 논문 포함 여부): T002 자료 목록을 만들 때 정한다.
- 생성형이 아닌 기계 번역 도구(신경망 번역기)의 표기: 라벨 지침 4절의 임시 규칙을 따르고 T002에서 확정한다.
